# Python Mini Projects

This folder contains the projects I build while learning Python.

I am using these projects to move from understanding Python syntax to actually building things with Python. Instead of only solving individual problems, I am practicing concepts by building projects, debugging them, and improving them step by step.

## 1. Core Python Mini Projects

These projects focus on strengthening my Python programming fundamentals.

* Student Information Program
* Number Guessing Game
* Scientific Calculator
* Student Grade Management System
* Expense Tracker
* Library Management System
* Command-Line Task Manager

Through these projects, I am practicing variables, conditions, loops, functions, lists, dictionaries, file handling, exception handling, modules, and OOP basics.

## 2. Python Data Mini Projects

After building my core Python foundation, I am applying Python to work with and process data.

* Matrix Calculator
* Student Marks Analyzer
* CSV File Cleaner
* Student Data Analyzer
* Weather API Reader
* Sales Data Analysis

These projects help me practice NumPy, Pandas, data processing, data cleaning, APIs, JSON, basic analysis, and visualization.

## What I Am Learning

The goal of these projects is not simply to complete them. I want to understand the concepts, build things independently, make mistakes, debug my code, and gradually improve the way I write programs.

This is my first step toward building a strong foundation in **Data Engineering**, followed by **Machine Learning**.
